# Licensing

LogisBase uses a **dual-licensing model**: a source-available license for the community and a commercial license for proprietary use cases.

<Callout type="info">
  **Full license text:**
  [github.com/logisbase/logisbase/blob/master/LICENSE.md](https://github.com/logisbase/logisbase/blob/master/LICENSE.md)
</Callout>

## Source-Available License

The entire LogisBase platform — the core API, Console, official extensions (FleetOps, Storefront, Pallet, Ledger), and the mobile apps (Navigator App, Storefront App) — is released under a **Source-Available License**.

### What the Source-Available License allows

| Use case                                                           | Allowed?                       |
| :----------------------------------------------------------------- | :----------------------------- |
| Self-host LogisBase for your own operations                        | ✅ Yes, free                   |
| Use LogisBase to run a commercial logistics operation              | ✅ Yes, free                   |
| Modify LogisBase for internal use                                  | ✅ Yes, free                   |
| Build and publish your own extensions                              | ✅ Yes, free                   |
| Deploy LogisBase as a public-facing SaaS without releasing changes | ❌ Requires commercial license |
| Embed LogisBase in a closed-source product                         | ❌ Requires commercial license |
| White-label the console or mobile apps in a proprietary product    | ❌ Requires commercial license |

### The key requirement

<Callout type="warn">
  If you **modify** LogisBase source code and make it available over a network
  (for example, as a SaaS service your customers use), you must make your
  modified source code available to those users under the same source-available
  license.
</Callout>

This is the core requirement of our source-available model. It ensures improvements to the platform are shared back with the community. If your use case involves running an unmodified LogisBase instance for your operations — even as a paid service to your customers — you are not required to release any source code.

## Commercial License

If SOURCE-AVAILABLE does not fit your use case, a **Commercial License** is available. It lets you:

- Integrate LogisBase into proprietary, closed-source products without releasing your modifications
- White-label the Console and mobile apps (custom branding, logos, app name) without source-available obligations
- Distribute modified versions of LogisBase privately
- Receive priority support, SLA guarantees, and direct access to the core team

Commercial licenses are tailored to your organisation's size and use case. For full details on licensing options, pricing tiers, and terms, see the [LogisBase Licensing page](https://logisbase.com/licensing).

If you're unsure whether your use case requires a commercial license, reach out at [hello@logisbase.com](mailto:hello@logisbase.com) with a brief description of how you plan to use LogisBase. We'll give you a straight answer.
